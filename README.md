# Become A VAPT Manager — Complete Handbook

> A 300+ page handbook taking you from absolute beginner to VAPT Manager/Director.
> Covers Web, Network, Mobile, Cloud, DevSecOps, IoT, AI/ML, OT, Thick Client, Blockchain,
> and Security Management — with diagrams, real-life scenarios, document templates and
> hands-on labs.

## 📖 How to Read

Open [`index.html`](index.html) in any modern browser. From there, every part links to the
next. All 16 chapter files share a common stylesheet (`chapters/style.css`).
