🌍 Chapter 15 — Network Reconnaissance

15.1 External Recon — OSINT for Network Range

# Step 1: Discover IP ranges owned by target
$ whois target.com | grep -i "inetnum\|cidr\|netname"
$ whois -h whois.arin.net target.com

# Step 2: Search ASN
$ whois -h whois.radb.net '!gAS32934'

# Step 3: BGP route lookup
$ bgpview.io — web
$ asnlookup.com — web
$ curl -s https://stat.ripe.net/data/prefix-overview/data.json?resource=AS32934 | jq

# Step 4: Reverse whois — find related orgs / domains
$ whois target.com | grep "OrgName\|Organization"
$ whois -h whois.arin.net "e !search@org ARIN-ORG-SOMETHING"

# Step 5: Certificate transparency logs
$ curl -s 'https://crt.sh/?q=%25target.com&output=json' | jq -r '.[].name_value' | sort -u

# Step 6: Shodan / Censys / FOFA — exposed devices
$ shodan search "org:TargetCorp" --fields ip_str,port,product
$ censys search "target.com"

# Step 7: Google dorking (subdomains, files)
$ inurl:target.com ext:sql | ext:cfg | ext:log
$ site:target.com intitle:"index of"

15.2 Active Recon — Host Discovery

# ── Ping sweep ──
$ nmap -sn 192.168.1.0/24            # ICMP only
$ nmap -Pn -PS21,22,80,443 10.0.0.0/24  # Skip ping, TCP SYN to ports
$ nmap -sn -PR 192.168.1.0/24        # ARP scan (LAN only — most accurate)

# ── Using masscan for speed ──
$ masscan -p1-65535 --rate 10000 10.0.0.0/24 -oL masscan.txt
# Scans whole /24 in ~30 seconds

# ── ARP discovery (LAN) ──
$ netdiscover -r 192.168.1.0/24
$ arp-scan --localnet

15.4 Nmap Scripting Engine — Your Goldmine

# Default scripts (safe)
$ nmap -sC -sV target         # scripts + version

# Vuln scanning
$ nmap --script=vuln target

# Specific categories
$ nmap --script=exploit target
$ nmap --script=brute target
$ nmap --script=discovery target
$ nmap --script=auth target

# Banner grabbing
$ nmap -sV --script=banner target

$ nmap -sS -sV -sC -O -Pn -p- --script=vuln,exploit,brute,default -oA full_scan target

15.5 Fast-Scan Methodology

"Big 4" Scan Types

# 1) Quick discovery — find live hosts
$ nmap -sn 10.0.0.0/24 -oG live.txt
$ grep "Up" live.txt | cut -d' ' -f2 > ips.txt

# 2) Top-port scan on live hosts
$ nmap -sS -p 21,22,23,25,53,80,110,135,139,143,443,445,993,995,1433,3306,3389,5432,5900,5985,5986,8000,8080,8443,9200,27017 -iL ips.txt -oA topports

# 3) Full port scan on interesting hosts (slower)
$ nmap -sS -p- --min-rate 5000 -iL interesting.txt -oA fullports

# 4) Service version & vuln scripts on found services
$ nmap -sV -sC --script=vuln -p <open ports> target -oA services

# Anonymous bind
$ ldapsearch -x -H ldap://target -b "dc=target,dc=com" "(objectClass=*)"

# Find privileged accounts
$ ldapsearch -x ... '(&(objectClass=user)(adminCount=1))' sAMAccountName

18.2 LLMNR/NBNS Poisoning (Initial Access)

# Run Responder on attacker
$ sudo responder -I eth0 -wrf

# Wait — victim mis-typoes host or DNS fails

$ ls -la /usr/share/responder/logs/

19.4 Reporting Time

The single biggest mistake novice testers make is rushing end-to-end "pwn" attacks without documenting along the way. Treat the report as a court document. Every step must be reproducible. Always screenshot the time/clock of every command.
